# Sandeep & Anchal — Wedding Invitation Website

A responsive traditional Indian wedding invitation website built with standard HTML5, CSS3, and JavaScript.

## 100% Free of Cost Guarantee

All resources, assets, tools, and services used in this project are completely **free of cost ($0.00)**:

1. **Embedded Google Maps:**
   - Uses the public, keyless Google Maps iframe embed (`https://maps.google.com/maps?q=...&output=embed`).
   - Requires **NO API key**, **NO credit card**, and **NO Google Cloud account**. Completely free for unlimited views.
2. **Local Image Assets (`assets/images/`):**
   - All backgrounds and gallery images are downloaded directly into the repository.
   - Requires zero external image hosting and has no bandwidth fees or hotlinking limits.
3. **Wedding Song (`wedding-song.mp3`):**
   - Stored directly inside the project root.
   - Zero streaming or audio CDN fees.
4. **Google Fonts (Cormorant Garamond & Hind):**
   - 100% open-source and free under the SIL Open Font License (OFL).
5. **Hosting:**
   - 100% free hosting options via **GitHub Pages**, **Vercel**, **Netlify**, or **Cloudflare Pages**.

## File Structure

- `index.html` — Wedding invitation sections, event schedule, venues, interactive Google Map, audio player widget, flower petal shower button, and direct WhatsApp wishes button.
- `styles.css` — Royal maroon and gold palette, typography, responsive card layouts, audio equalizer animations, and falling flower petal animations.
- `script.js` — Live countdown, mobile navigation, WhatsApp invitation share, direct wishes link, Plus Code copy button, music toggle, and interactive petal shower generator.
- `wedding-song.mp3` — Background wedding music file.
- `favicon.svg` — Custom vector logo favicon.
- `assets/images/` — Local high-resolution wedding photos and backgrounds.

## How to Run Locally

Double-click `index.html` to open it in any modern browser (Chrome, Safari, Edge, Firefox). No build step, node modules, or installations required.

---

## Publish 100% Free on GitHub Pages

1. Create a **public** repository on GitHub (e.g., `sandeep-anchal-wedding`).
2. Upload all files and folders (`index.html`, `styles.css`, `script.js`, `wedding-song.mp3`, `favicon.svg`, and the `assets/` folder).
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch** -> branch `main` -> folder `/ (root)`.
5. Click **Save**. Your free website will be live in 1–2 minutes!
